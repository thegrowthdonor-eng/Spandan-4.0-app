# SPANDAN 4.0 — Design brief and content plan

Version 1.0 | 14 October 2026

## Premium festive visual direction

The accepted direction is premium festive: refined typography, rich colours, purposeful imagery and controlled animation. SPANDAN 4.0 should feel like a carefully designed cultural festival while keeping forms and results readable. This document proposes a direction; it does not claim an approved logo or final palette.

| Element | Proposed treatment |
| --- | --- |
| Palette | Deep aubergine #261923, warm ivory #F5F0E8, muted brass #B49A68, restrained coral #BC6256. Contrast-test actual text/background pairs; brass is an accent. |
| Typography | Refined display serif for short fest/editorial titles, neutral sans serif for UI. Regular/medium weights; avoid bulky headline lettering. Final licensed font selection pending. |
| Imagery | Real performance, sports and campus photography; carefully cropped hero/feature imagery. No invented artist endorsements or fake event photos. |
| Layout | Generous spacing, crisp cards, restrained borders, strong hierarchy. Decorative surfaces on promotional pages; clean forms and scoreboards. |
| Motion | Short transitions, gentle reveals and score-change feedback. No constant particles, neon glow or autoplay audio. Respect reduced motion. |
| Mobile | Bottom navigation, thumb-friendly actions, sticky Apply/status area, clear filters; optional PWA install suggestion after useful engagement |

### Screen composition

Home begins with fest identity, date, one strong image and Explore/Register actions. Follow with a pinned notice, happening-now/upcoming strip, event categories, Main Stage feature, sponsor section and social/footer links. The pre-fest version uses countdown and registration deadlines; the live version prioritises timings and scores.

Event detail places rules, eligibility, timing, venue and head before the application action. My Fest separates access status, application status and selection. The score screen uses tabular numbers and distinct match states; colour alone must not communicate winning or cancelled status.

All sample art, artist names and sponsor marks must be labelled placeholders in development. Final approval of logo, tagline, palette and images remains with the organising committee.

## Content ownership and festival inspiration

| Content | Owner and publishing requirement |
| --- | --- |
| Fest identity and dates | Main admin; confirm official college name, edition and organising line |
| Rules and event pages | Assigned head; mandatory eligibility, format, deadlines, venue, contacts and selection method |
| Scores and results | Assigned head; live updater named before event starts; corrections logged |
| Announcements | Admin globally; heads only for assigned events; expiry for urgent notices |
| Sponsors and merchandise | Committee; approved logos, rights, tiers, links and offline contact details |
| Stage reveals and media | Media team through admin; authorised artist announcement times and cleared photographs |
| Help and FAQs | Admin routes queries; proposed daytime response target 12 hours, with fest-day staffing published |
| Leaderboard rules | Committee; approve points and tie policy before any counted result |

### Pulse inspired patterns

Pulse's public site presents event categories, a participant dashboard/pass flow, schedules, live notices and scoreboards, gallery, sponsors, organising team and help links [S7]. Its older site also presents an anthem and aftermovie [S8]. These patterns inform SPANDAN's discovery, media and support sections. Their private implementation was not tested. SPANDAN uses one offline contribution and college-only verification; it does not copy Pulse's ticket/card checkout.

### Minimum content sheet

For every event collect: title, category, individual application questions, competition format, batch/gender/course eligibility where applicable, team/group limits, applicant and final-group capacities, rules file, registration dates, roster lock, reporting/start/end times, venue, head name/contact visibility, fixture type, score template and point eligibility.

### Deferred possibilities

Certificates, campus map, volunteer applications, scavenger hunts, student-submitted media and deeper analytics can be described in the roadmap after launch. They are not approved launch features. Do not add anonymous chat or additional data collection merely to appear interactive.
